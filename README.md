# Bypass proxy (ru)

![icon](icons/icon-128.png)

[English](i18n/README.en.md)

Расширение для Firefox, которое направляет российские сайты напрямую, а всё остальное — через прокси.

## Зачем

Многие российские сайты блокируют подключение через VPN. Расширение отправляет домены из базы geosite напрямую, остальное — через прокси.

## Установка

Установи из AMO, открой настройки и убедись, что в Firefox настроен системный прокси.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `proxy` | Направлять остальной трафик на системный прокси |
| `<all_urls>` | Читать домен запроса |
| `storage` | Хранить настройки локально |
