# Changelog

## 2.2.1

- Changed the interface colours to white.

## 2.2.0

- Added support for Firefox on Android.
- Added SOCKS5 support: host, port, optional username and password, and a "DNS through proxy" toggle that is on by default.
- If SOCKS5 is not set, routing is left to the browser proxy as before.

## 2.1.1

- Added extension icons in PNG, 32, 64 and 128 px.

## 2.1.0

- Initial release.
